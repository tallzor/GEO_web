# v0.3.0 品牌认知六要素规则

> 状态：已确认  
> 适用范围：品牌监测分析  
> 当前阶段只形成品牌认知洞察，不生成营销内容。

## 1. 模型定位

品牌认知六要素只用于品牌分析，与产品或服务使用的 BFABEWW 平行运行。模型形成品牌认知洞察，并在用户确认后作为品牌监测分析的认知基准。

## 2. 信息使用边界

- 只使用品牌自身事实和外部参考；
- 品牌事实以企业定义、品牌历史、价值观、业务范围、官方表达等定性信息为主；
- 不使用产品事实或产品认知洞察；
- 联网获得的信息只作为带来源的分析参考，不自动写回品牌事实字段；
- 缺少依据时输出“信息不足”，不得使用产品信息补齐品牌结论。

品牌缺少名称、标准行业或能够说明“品牌是什么、主要提供什么”的简介时，停止品牌六要素分析，并显示字段级缺失项。只有名称、只有行业，或只有名称加行业，均属于信息不足。从模型依赖看，品牌分析停止不阻断信息充分的产品执行 BFABEWW；但首次认知建立为了统一确认，仍须等待品牌和纳入产品全部通过预检后再启动批次。

## 3. 六个分析要素

1. **类别与定位**：品牌属于什么领域，希望以什么位置被认识。
2. **核心受众与场景**：品牌主要面向谁，希望在什么场景下被想到。
3. **品牌价值承诺**：品牌长期、稳定地承诺提供什么价值。
4. **品牌信任基础**：品牌为什么值得相信，包括历史、资质、专业能力和公开信誉依据。
5. **品牌特质与识别**：品牌希望以什么性格、语言和稳定识别元素被记住。
6. **认知边界**：品牌不是什么、不覆盖什么范围、不能作出哪些承诺。

## 4. 洞察输出

每个要素至少记录：

- 洞察结论；
- 支撑的品牌事实；
- 使用的外部参考；
- 支撑状态：依据充分、部分支持、信息不足或存在冲突；
- 缺失或冲突说明；
- 审核状态。

## 5. 审核与监测

- 用户可以修改、不采用或确认品牌认知洞察；
- 用户修改只进入认知洞察，不改变品牌事实；
- 首次同时生成品牌和产品洞察时，在同一个审核环节展示并一次确认；
- 确认后的品牌洞察成为品牌认知基准，供后续品牌监测分析使用；
- 品牌事实变化后，由用户决定是否更新洞察；未更新时继续使用原版本。

品牌监测只比较品牌认知基准与外部 AI 对品牌的实际认知；产品检测使用产品 BFABEWW 认知基准，两者不混用。
