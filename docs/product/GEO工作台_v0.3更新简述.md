# v0.3.0 更新说明简述

> 更新时间：2026-09-24  
> 本说明只列出当前已经实现的主要更新。

## 主要更新

1. **品牌与产品档案**：重构“品牌—产品/服务—竞品”创建流程，支持一个核心品牌管理多个产品或服务，并补充品牌、场景、优势、证据和限制等结构化字段。
2. **分析前预检**：在启动认知分析前统一检查品牌与产品信息，信息不足时返回字段级提示并保留已填写内容。
3. **知识附件**：支持按品牌或产品上传、展示、下载和删除资料，本版只保存原文件，不解析内容或自动抽取事实。
4. **认知洞察**：使用品牌认知六要素分析品牌、使用 BFABEWW 分析产品或服务，并支持异步运行、统一审核、修改后一次确认和主动更新版本。
5. **用户问题模拟器**：基于已确认的认知洞察、目标用户和决策场景，模拟生成无品牌、场景与对比、品牌直接三类候选问题。
6. **正式问题库**：支持候选问题审核入库以及正式问题的启用、停用和删除，每个品牌最多保存 240 道问题，单次检测选择 1—10 道。
7. **GEO 检测采集**：支持针对品牌或具体产品选择豆包、DeepSeek、混元（腾讯元宝）执行检测，并提供后台运行、进度持久化和失败单元重试。
8. **GEO 检测结果**：新增出现情况、自然出现、呈现位置、风险信号和引用来源统计，并支持按平台、问题和分析结论查看可追溯的回答明细。
9. **数据与权限**：新增认知、问题模拟和检测结果相关的 Supabase 持久化结构、后台 Worker、组织数据隔离和历史快照能力。

## 当前状态

v0.3.0 已完成“品牌与产品事实—认知洞察—问题库—AI 回答采集—基础结果报告”主流程；新版报告到优化目标、任务和复测的衔接仍待后续实现。
