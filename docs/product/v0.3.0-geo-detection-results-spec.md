# v0.3.0 GEO 检测结果规格

## 目标

本版本只处理一次 GEO 检测所采集的 AI 回答，输出可追溯的事实统计，不计算综合分，也不生成品牌治理建议。

## 检测对象

- 检测对象只能是一个品牌或一个产品/服务。
- 品牌检测只使用品牌名称和品牌简称识别目标。
- 产品检测只使用产品/服务名称识别目标；只出现母品牌不算产品出现。
- 品牌背景可以帮助理解产品，但不能替代产品名称的实际出现。

## 处理流程

1. 固化检测对象、问题、平台和品牌背景快照。
2. 采集并持久化原始回答及引用。
3. 使用确定性规则识别名称出现、次数、首次位置和直接点名问题。
4. 使用底座模型判断呈现位置和风险信号。
5. 校验判断依据必须逐字存在于原回答；无效依据触发保守降级。
6. 规范化引用 URL，按明确规则分类并去重。
7. 使用纯程序汇总批次统计和关键发现。

## 单条回答分类

### 呈现位置

- `top_recommendation`：首位推荐
- `alternative`：备选方案
- `general_mention`：一般提及
- `risk_warning`：风险提醒
- `negative_counterexample`：负向反例
- `not_mentioned`：未出现

### 风险信号

- `none_detected`：未发现风险信号
- `cautious_description`：谨慎描述
- `negative_counterexample`：负向反例

“未发现风险信号”只表示本次回答中没有识别到，不表示现实中不存在风险。

### 引用来源

- 行业协会
- 权威媒体
- 研究机构
- 标准组织
- 高可信平台
- 品牌官方
- 其他
- 无法判断

来源类型不是引用内容正确性，也不是来源质量评分。

## 统计口径

- 出现率：出现检测对象的回答数 / 有效回答数。
- 自然出现率：未直接点名检测对象的问题中，出现检测对象的回答数 / 对应有效回答数。
- 呈现位置分布：以出现检测对象的回答为口径；未出现单独展示。
- 风险信号分布：只统计出现检测对象的回答。
- 引用来源分布：只统计出现检测对象的回答中的独立引用 URL。
- 失败回答不进入有效回答分母，页面必须明确显示失败数量。

## 持久化

- 原始回答保存在 `detection_results`。
- 逐条分析保存在 `detection_analyses`。
- 批次汇总保存在 `detections.result_summary`。
- Worker 每完成一个批次即保存进度，重启后从缺失单元继续。
- Supabase 是线上唯一数据源；本地文件 adapter 仅用于开发和自动化测试。
