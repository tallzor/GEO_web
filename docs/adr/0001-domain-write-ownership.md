# 按领域仓储划分远程写入所有权

远程模式下，Zustand 只保存界面读取投影，不作为数据库事实来源。启动时允许把多个领域组合成一个工作区读取投影，但该投影不可整包回写。工作区写入编排只接受明确的写入范围，完成关系校验后将命令交给相应领域仓储。

常规写入所有权如下：

- 账号资料命令负责当前用户的名称、手机号以及认证元数据；工作区同步不再写用户资料。
- 品牌仓储负责品牌档案及其门店、产品、竞品、知识附件元数据和检测问题。附件上传、附件删除、AI 问题保存也必须进入该仓储。
- 检测仓储负责检测批次、回答、分析、诊断和优化建议内容。
- 优化仓储负责优化周期、七天任务、内容及内容版本；它只更新优化建议的“已采用”状态，不修改建议内容。
- 发布仓储负责平台账号、发布批次和发布结果。发布结果引起的内容、任务和周期状态变化必须调用优化仓储的进度命令。
- 工作区写入编排负责当前品牌偏好、写入范围路由和成功后的审计记录，不直接持有品牌、检测、优化或发布表的写入规则。

品牌整体删除是明确的跨领域例外，由品牌生命周期服务在完成活动流程检查后执行软删除并修正当前品牌偏好。服务端已持久化的结果合并到 Zustand 时必须标记为读取投影更新，禁止再次触发通用工作区回写。

所有管理端写入在落库前必须校验组织归属和父子关系；对状态推进等更新必须确认实际命中记录，不能把零行更新当成成功。多表写入保持可重试和尽量可补偿：周期创建、首次内容版本保存、附件上传在后续步骤失败时清理本次创建的数据；其余幂等写入由同步协调器保留范围并重试。
